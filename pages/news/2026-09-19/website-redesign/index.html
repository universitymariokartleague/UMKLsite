Website Redesign!

19/09/2026 | Website Branding Season 3
Written by zy

September 2026 Website Redesign

The UMKL site has received a refresh, in-line with new brand guidelines, which will be published soon!

In preparation for Season 3, the UMKL website has been refreshed. Expect a more consistent brand style across all of the UMKL. Lots of news articles will be posted shortly, so be sure to check it out! Prepare to get excited as Season 3 is right around the corner!

Thanks to everyone who helped design and test the site! More content will be released soon.

The redesigned website has better support for higher resolution screens

Here is a full list of changes made to Cheep Cheep and the UMKL site below:

Cheep Cheep/Discord
- Fixed a bug that showed York as having 1 season win when they had 2
- Majorly refactored the bot's code base into cogs and folders for easier maintenance
- Added the ability for server members to /request-stream-key, /request-board-password and /request-media-password
- Added various admin commands
- Increased the team name length limit to 16 characters
- Added captchas that new members must complete before accessing all the channels in the server, sadly it's necessary as Discord can't make their own platform usable
- Added /export-my-data, which lets you download all the data UMKL holds on you
- Added automatic database backups
- Cheep Cheep now serves profile pictures and team emblems directly (used by the credits and teams pages)
- Added /change-team-name for admins
- Added Best Match Score leaderboards (season/lifetime, team/individual) to /leaderboards
- Team locations shown by Cheep Cheep now link to Google Maps
- Cheep Cheep now suggests using /disconnect when someone mentions disconnecting in a match chat
- Added fun dev commands
- Fixed various timezone and daylight saving time bugs affecting match and event times
- Fixed a bug where SP sometimes wasn't applied properly after a match ended
- Fixed a bug where SP history could be lost for some players
- Various performance improvements
- Fixed various bugs
- Fun fact Cheep Cheep runs on an AMD Ryzen 3 2200G with 16GB of RAM
- Another fun fact Cheep Cheep uses about 120MB of RAM
UMKL website
- Resigned entire website with a modern design
- Added a list of all teams underneath the current season's teams
- Added the ability to add a 'UMKL Matches' calendar to your calendar app
- Redesigned the live results page to work at any screen resolution, and with team parameters
- Made it obvious who the winner is on the teams page
- Rewrote all help/guide articles
- Added a downloadable assets pack containing team logos and emblems
- Added a search bar to the news page
- Revamped the tools page
- Various performance and page loading speed improvements across the site
- Added a disclaimer on the matches page for users viewing match times from outside the UK
- Fixed bugs and oversights
